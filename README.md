# NCU 健身器材指南與個人化訓練課表（MVP）

這是一個依據產品規格實作的 MVP 示範程式，聚焦核心流程：

1. 搜尋或拍照輔助確認中央大學校內健身房器材
2. 查看審閱過的教學內容與安全提醒
3. 產生可確認的基礎課表，並在回饋後取得保守調整建議（需使用者確認）

> 重要聲明：本工具僅供一般訓練參考，不構成醫療診斷、治療或成果保證。若有疼痛、暈眩、胸悶、嚴重或持續症狀，請立即停止並尋求醫療協助。

## MVP 範圍

- 深入收錄 3 項示範器材：啞鈴、腿推機、滑輪下拉機
- 器材名稱搜尋與肌群篩選
- 拍照輔助辨識（低風險 fallback：不確定時要求使用者確認/搜尋，不提供未驗證建議）
- 依目標、經驗、時間、可用器材與限制產生基礎課表
- 顯示來源、審閱狀態、替代動作、停止訓練提醒
- 回饋後提供保守調整建議，需使用者確認才套用

## 安裝與執行

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

啟動後開啟 http://127.0.0.1:5000 。

## 測試

```powershell
.\.venv\Scripts\Activate.ps1
pytest -q
```

## 專案結構

- `app.py` - Flask 路由與頁面流程
- `equipment_data.py` - 器材示範資料（含審閱狀態、來源、更新日期）
- `plan_generator.py` - 保守的規則式課表產生與調整建議
- `templates/` - Jinja HTML 模板
- `static/` - CSS 與示意圖
- `tests/` - pytest 測試

## 資料與安全原則

- 器材內容標示審閱狀態、來源與更新日期；示範資料上線前需專業審閱。
- 不診斷傷病、不提供醫療建議、不保證成果。
- 課表調整建議為保守方案，且需使用者確認後才套用。
- 使用者限制/不適僅作一般訓練提醒，不做醫療判定。
